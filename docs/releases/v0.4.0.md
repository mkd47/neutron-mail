Neutron Mail 0.4.0 adds undo send, automatic draft saving and automatic replies, and tidies up the reading pane.

## Install (Fedora 44)

```sh
sha256sum -c SHA256SUMS
sudo dnf install ./neutron-mail-0.4.0-1.x86_64.rpm
```

Upgrading from 0.3.0 keeps your accounts, cache and settings.

## New

- **Undo send:** after you press Send, the message waits 10 seconds. A bar in the bottom-left shows the countdown with **Undo** (or **Ctrl+Z**) and **Send now**. Undo reopens the message so you can fix it. If sending fails, the message reopens by itself and nothing is lost. Quitting during the countdown sends the waiting mail first; if that fails, the message is kept in Drafts. Change the delay (off, 5–30 seconds) under Account settings → Undo send.
- **Drafts save themselves** every 30 seconds while you write, replacing the previous copy, and the composer shows when it last saved. Discard removes the saved draft, and sending removes it after delivery. Servers without UIDPLUS can't replace drafts, so autosave pauses there and Save draft still works.
- **Automatic replies** (Account settings → Automatic replies): a message, an optional subject, optional start and end dates, and how often the same sender may be answered. Mailing lists, newsletters, no-reply addresses and other automatic mail are never answered (RFC 3834).
  - **From this computer** works with every mail server, including 263.net, but only while Neutron Mail is running.
  - **On the mail server** keeps replying while the computer is off, on servers that offer ManageSieve with vacation. For 263, Gmail, Outlook and Alimail, the settings point to the provider's own webmail auto-reply.
- **Tidier reading pane:** one toolbar with icon buttons and a "More" menu, the other messages of a conversation as compact cards, and attachments grouped into one bar that expands to a list. **Save all** saves every attachment into a folder without replacing existing files.
- **Readable mail in dark mode:** HTML mail that sets its own colours is shown on a light page inside the dark window. "Always use a light background for mail" is in the More menu.

## Fixed

- Images shown in the message body (signature logos and the like) no longer count as attachments.
- Clicking a new-mail notification brings the window forward and opens the message.
- Folder names containing "&" (like "R&D") are shown correctly.
- The calendar strip above the reading pane only appears when something is scheduled in the next 7 days.

## Known limitations

- Automatic replies sent from this computer only go out while Neutron Mail is running and syncing.
- Only an RPM for Fedora 44 (x86_64) is built.

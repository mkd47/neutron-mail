Neutron Mail 0.3.0 adds the everyday message actions, conversations, sender aliases, printing and contact cards, and fixes the "busy syncing" error from 0.2.0.

## Install (Fedora 44)

```sh
sha256sum -c SHA256SUMS
sudo dnf install ./neutron-mail-0.3.0-1.x86_64.rpm
```

Upgrading from 0.2.0 keeps your accounts and cache. On first start, mail you already have is grouped into conversations in the background.

## New

- **Message actions:** Archive, Delete (to Trash, with Undo), Junk / Not junk, Mark read/unread and Star from the toolbar above a message, a right-click menu in the list, or the keyboard: **Del**, **A**, **!**, **U**, **S**. They work on several selected messages. In Trash, or with **Shift+Del**, messages are deleted permanently after you confirm (needs a server with UIDPLUS).
- **Conversations:** replies are grouped into one row with a message count. The reading pane lists every message of the conversation, including your replies from Sent. Actions apply to the whole conversation, and opening it marks it read. Use the "Conversations" toggle above the list to see single messages instead.
- **Contact cards:** click a sender, recipient or profile picture for New message, Copy address, Add to contacts (GNOME address book) and Trust sender (always load remote images). Long recipient lists collapse to "+N more".
- **Sender addresses (aliases):** add them under Account settings → Sender addresses. The composer gets a From picker, and replies use the alias the message was sent to. Your mail server must allow sending as each alias.
- **Print** (**Ctrl+P**): opens a preview with just the message and the print dialog.
- **Resizable composer:** the New message window can be resized and maximized; the inline reply has a drag handle.

## Fixed

- "invalid input: This account is busy syncing" no longer appears at startup: a second sync waits for the running one.
- Very large first syncs continue in 15-minute rounds instead of stopping with a time-limit error.

## Known limitations

- A single message that takes longer than 60 seconds to download is retried on the next sync.
- Only an RPM for Fedora 44 (x86_64) is built.

Neutron Mail 0.5.1 asks before opening attachments that can run code, retries automatic rules that fail partway, and uploads a new server-side Sieve script when local rules have changed.

## Install or update (Fedora 44)

```sh
curl -fsSL https://raw.githubusercontent.com/mkd47/neutron-mail/main/scripts/install.sh | bash
```

The script downloads the RPM and `SHA256SUMS` of the latest release, checks the checksum and installs with `dnf`. Or by hand:

```sh
sha256sum -c SHA256SUMS
sudo dnf install ./neutron-mail-0.5.1-1.x86_64.rpm
```

Upgrading from 0.5.0 keeps your accounts, cache and settings. Rules that already ran stay finished. An uploaded Sieve script that has no recorded hash is checked on the next sync and uploaded again only if the server copy differs.

## Fixed

- Opening an HTML, XHTML, SVG, or similar active attachment asks for confirmation, including when the file was renamed. The check uses the extension, the MIME type, and a short look at the start of the file (including a normal SVG prologue and a UTF-16 document).
- Reading an attachment you are about to send stops at 25 MB on the opened file. A file that grows, or is replaced by a pipe or device, cannot bypass the limit or stall the send.
- OAuth sign-in keeps waiting if the browser's first callback connection is reset or sits idle.
- The shared UI package is downloaded as an HTTPS archive with an integrity hash. Builds no longer need GitHub SSH.
- Automatic rules record each action as it succeeds. A failed move, copy, or forward is retried with backoff, up to five times, and an action that already succeeded is not repeated. The failure is reported once.
- A local edit to server-side rules or the automatic reply is uploaded again when it no longer matches the script last sent to the server.

## Known limitations

- Scheduled mail is sent by Neutron Mail itself: it goes out only while the app runs (or at the next start).
- The installer checks the download's checksum, which catches broken downloads; it does not verify a signature.
- Only an RPM for Fedora 44 (x86_64) is built.

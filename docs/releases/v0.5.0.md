Neutron Mail 0.5.0 adds search filters, send later, templates, a signature per sender address, text size and a compact list, .eml and mbox import/export, and an update notice with a one-line installer.

## Install or update (Fedora 44)

```sh
curl -fsSL https://raw.githubusercontent.com/mkd47/neutron-mail/main/scripts/install.sh | bash
```

The script downloads the RPM and `SHA256SUMS` of the latest release, checks the checksum and installs with `dnf`. Or by hand:

```sh
sha256sum -c SHA256SUMS
sudo dnf install ./neutron-mail-0.5.0-1.x86_64.rpm
```

Upgrading from 0.4.0 keeps your accounts, cache and settings.

## New

- **Search filters:** `from:`, `to:`, `subject:`, `has:attachment`, `is:unread`, `is:read`, `is:starred`, `after:` and `before:` (YYYY-MM-DD), combined with ordinary words. The filter button next to the search box adds them. While searching, choose **All folders** or **Only** the open folder.
- **Send later:** the arrow next to **Send** offers this evening, tomorrow morning or afternoon, Monday morning, or any date and time. Scheduled mail is listed under **Scheduled** in the sidebar, with Send now, Change time, Edit (back to Drafts) and Delete. Neutron Mail sends it at that time; if the app is closed then, it goes out when you next open it. If sending fails (for example offline), it keeps trying for about 12 hours.
- **Templates:** **Templates** in the composer inserts a saved text where the cursor is, or saves the current message as a template.
- **A signature per sender address:** each alias in Account settings → Sender addresses can have its own signature. Changing **From** swaps the signature, and replies use the one of the address the mail was sent to.
- **Text size:** **Ctrl +**, **Ctrl −** and **Ctrl 0** change the size of the open message (also under More → Text size).
- **Compact list:** the list icon above the messages hides previews to fit more messages.
- **Save as .eml** (More menu), and **Import messages…** (right-click a folder) from .eml files or mbox exports (Thunderbird, Apple Mail, Gmail Takeout).
- **Update notice:** the sidebar shows "Update available" when a newer release is out, with the install command to copy. It can be turned off under Account settings → Updates.

## Fixed

- Dragging a conversation to a folder moves the whole conversation, not just its newest message.
- Security: HTML mail sanitizer (ammonia) updated to 4.2.4 for RUSTSEC-2026-0373 (CSS `url()` with unusual capitalisation).

## Known limitations

- Scheduled mail is sent by Neutron Mail itself: it goes out only while the app runs (or at the next start).
- The installer checks the download's checksum, which catches broken downloads; it does not verify a signature.
- Only an RPM for Fedora 44 (x86_64) is built.
